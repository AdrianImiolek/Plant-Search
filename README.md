# Plant Search
 
## Short Description
 
Plant Search is a fullstack web application that allows users to search for plants and browse detailed information about them. The frontend communicates with a custom backend, which handles API requests to an external plant data source, keeping sensitive credentials secure on the server side.
 
## Tools Used
 
- **React** — component-based UI library
- **React Router** — client-side routing between pages
- **Tailwind CSS** — utility-first CSS framework for styling
- **Vite** — fast build tool with Hot Module Replacement (HMR)
- **dotenv** — environment variable management for API keys
- **Node.js / Backend** — custom server to proxy requests to the external plant API
- **ESLint** — code linting and quality enforcement
- **Prettier** — code formatting (with Tailwind CSS class sorting)
- **Vercel** — deployment and hosting
## What I Learned
 
- Building a fullstack application with a separate frontend and backend
- Using React Router to handle navigation between multiple views
- Integrating Tailwind CSS for fast and consistent UI styling
- Securing API keys with environment variables and a backend proxy
- Fetching and displaying data from an external third-party API
- Managing a more complex project structure compared to single-page static sites
